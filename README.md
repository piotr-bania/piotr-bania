## 🛡️ BI Surface

Open-source cybersecurity project combining a local <strong>Python / FastAPI agent</strong> with a <strong>Next.js / TypeScript interface</strong>.

Current capabilities include:

- local agent connection and state management
- static system information
- live CPU and memory telemetry
- uptime tracking
- separated static and dynamic telemetry
- colour-coded connection states
- light / dark / system appearance modes
- English and German documentation

Long-term direction:

- process visibility and parent-child relationships
- sockets and network connection mapping
- event collection and investigation timelines
- behavioural detection rules
- MITRE ATT&CK mapping
- controlled attack simulations
- explainable alerts and defensive response
- optional host containment while preserving BI Surface communication

<strong>Stack:</strong> Python · FastAPI · Next.js · TypeScript · Tailwind CSS · SCSS
